# calibrate is now add-flow

`/docsxai:calibrate` is now `/docsxai:add-flow`. The old name is deprecated since 0.3.0 and will be removed in 0.5.0. Load the `add-flow` skill and follow it (`skills/add-flow/SKILL.md` in this plugin). The CLI command it ends in is now `docsxai add-flow`; the old CLI name still runs it, with a deprecation line on stderr.
