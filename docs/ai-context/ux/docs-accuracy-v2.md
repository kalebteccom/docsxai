# Docs accuracy pass v2: what `0.3.0-rc.2` added

Second read of the public docs against the code, for what `0.3.0-rc.2` added: `pack` (workspace and matrix sources, `--check`, `--against`, `--threshold`, `--no-optimise`, `DOCSX_OXIPNG_BIN`), the flow matrix, `run --verify-determinism`, `burn --report`, `doctor`, the `pull` and `push` rules, the egress guard variables, the `@next` install pins, the CI recipes, the repo-only packages and the MCP HTTP transport.

Scope: `README.md`, `website/src/content/docs/**`, `packages/*/README.md`, `docs/public-surface.md`, `docs/ci-recipes.md`, `docs/agent-runbook.md` and `docs/ai-context/**`. Nothing was run: no build, no test, no browser, no registry call. Every row below was settled by reading the file named in the third column. Doc lines are as of `bc2e031`, before the fixes; code lines are on the current tree.

The cross-check that keeps the CLI part true is `packages/engine/test/docs-cli-mentions.test.ts`. It reads the README, the getting-started and reference pages and the determinism guide, takes every `docsxai <command> [--flag]` from a code span or a shell block (`$ ` lines only, when a block has them), and fails with `file:line` when the command or a flag is not in the `docsxai --help` usage text. `doctor --help` is the one flag it allows beyond the usage text, and it checks that `doctor --help` exits 0. Blocks of other languages are skipped, and a shell block opts out with `not-docsxai` after its language. The CI recipes keep their own suite, `ci-examples.test.ts`.
